    Desktop console: quick guide

    What it is

    The desktop console shows every RTU on the Reach route, what is running on each, and lets you start and cancel bulk tests from one screen. It uses the same sign in and service as the mobile app, and only named accounts can use it. Nothing here changes the mobile app.

    The RTU list (left)

    Cables start collapsed. Click a cable to show the RTU at each end, then click an RTU to open it. Collapse all / Expand all is at the top.

    Available: FMS reports the RTU attached and nothing is running on it. Testing: an FMS bulk Task, an E2E run using it at either end, or a Uni-dir tone from it. Offline: FMS reports it not attached, or has no routes for it ("not in FMS"). Checking: waiting for FMS, normally a few seconds after opening.

    Lights refresh every minute, running Tasks and tones every 5 seconds. Tests started with Test On Demand in the FMS screen create no Task, so they cannot be seen.

    RTU tabs

    • Tasks: bulk Tasks on this RTU with progress. Cancel… stops one at any point: finished fibres keep their results, the rest never run. Cancelling someone else's Task asks you to confirm whose it is. A cancelled Task drops off the FMS Tasks page but stays in Run history here.
    • Bulk Test: pick fibres (ribbon buttons, or type e.g. 61-72, 80), choose OTDR or iOLM and the settings, then Start.
    • E2E Continuity: this RTU tones and the far end RTU runs the OTDR (Swap to turn it round). Pick ribbons and press Start. The results grid fills in live: green straight, amber crossed (shows the fibre it lands on), red DIS or not found. Pause, Stop, Resume and a CSV export are on the run. The run carries on at the relay if you close the page.
    • Tone (Uni-dir): tone one fibre at a time from this RTU while someone at a joint confirms it. START tones the first fibre, NEXT confirms it and tones the next. Mark DIS, Crossed or a note. Click any fibre on the map to move there, then press START to tone it. Keys: Space or → Next, ← Back, R Repeat, D DIS, X Crossed. Finish saves it to Run history.

    Starting a bulk test

    1. Pick the RTU on the left, then the Bulk Test tab.
    2. Pick fibres. The comment fills in as the RTU and fibres (e.g. RGAC2 F061-F063); type over it if you want.
    3. OTDR: wavelengths (each wavelength is a separate FMS Task, because FMS fires one wavelength at a time), duration, and automatic or set pulse and range. iOLM: test limit, acquisition type and wavelengths (all in one shot).
    4. Press Start. FMS first confirms every fibre exists on that RTU and nothing is started yet; you then see one summary (fibres, Tasks, time, anything already running) and press OK to start.

    Time guide, measured on RGAC2: OTDR about the acquisition time plus 17 s per fibre per wavelength; iOLM Standard about 73 s per fibre. If an RTU is already busy, FMS shares it between Tasks, so both take longer.

    Run history

    Finished work: every E2E run, Uni-dir session and FMS bulk Task, including cancelled ones. (The Tasks tab is different: it shows bulk Tasks running on one RTU now, and lets you cancel them.) It opens on Today, which is quickest; choose 7, 30 or 90 days for more. "App runs only" skips the FMS Tasks and loads fastest. The last list shows at once while it refreshes. Filter by result, type, RTU and person, click a row for detail, or export a CSV.

    Who is online

    The pill at the top shows who is signed in (mobile or desktop) and what is running. Click it for the list.
