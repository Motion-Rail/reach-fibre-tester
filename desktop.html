    Finding your way

    • Overview: the route map, everything running, who is online and what finished today.
    • Tasks ▾: Running now and Run history. In Run history click a run to see its report; Download files and Export CSV are there too.
    • Tools ▾: Real Time, Single Test, E2E Continuity, Tone Test, Bulk Test. Each asks which cable and end first and remembers it.
    • Cable View: every fibre of a cable; ▾ to pick a cable, find a fibre or get the Excel report.
    • Your name (top right): Alerts, Light or Dark, Help, Mobile view, Sign out.

    Tasks and Tools open a list. Overview and Cable View go straight to their page.

    What it is

    The desktop console shows every RTU on the Reach route, what is running on each, and lets you start and cancel bulk tests from one screen. It uses the same sign in and service as the mobile app, and only named accounts can use it. Nothing here changes the mobile app.

    The RTU list (left)

    Cables start collapsed. Click a cable to show the RTU at each end, then click an RTU to open it. Collapse all / Expand all is at the top.

    Available: FMS reports the RTU attached and nothing is running on it. Testing: an FMS bulk Task, an E2E run using it at either end, or a Uni-dir tone from it. Offline: FMS reports it not attached, or has no routes for it ("not in FMS"). Checking: waiting for FMS, normally a few seconds after opening.

    Lights refresh every minute, running Tasks and tones every 5 seconds. Tests started with Test On Demand in the FMS screen create no Task, so they cannot be seen.

    Tools (the tabs for the RTU you picked)

    • Tasks: bulk Tasks on this RTU with progress. Cancel… stops one at any point: finished fibres keep their results, the rest never run. Cancelling someone else's Task asks you to confirm whose it is. A cancelled Task drops off the FMS Tasks page but stays in Run history here.
    • Bulk Test: pick fibres (ribbon buttons, or type e.g. 61-72, 80), choose OTDR or iOLM and the settings, then Start.
    • E2E Continuity: this RTU tones and the far end RTU runs the OTDR (Swap to turn it round). Pick ribbons and press Start. The results grid fills in live: green straight, amber crossed (shows the fibre it lands on), red DIS or not found. Pause, Stop, Resume and a CSV export are on the run. The run carries on at the relay if you close the page.
    • Tone (Uni-dir): tone one fibre at a time from this RTU while someone at a joint confirms it. START tones the first fibre, NEXT confirms it and tones the next. Mark DIS, Crossed or a note. Click any fibre on the map to move there, then press START to tone it. Keys: Space or → Next, ← Back, R Repeat, D DIS, X Crossed. Finish saves it to Run history.

    Starting a bulk test

    1. Tools ▾, Bulk Test, then pick the cable and the end to test from (or pick the RTU on the left and the Bulk Test tab).
    2. Pick fibres. The comment fills in as the RTU and fibres (e.g. RGAC2 F061-F063); type over it if you want.
    3. OTDR: wavelengths (each wavelength is a separate FMS Task, because FMS fires one wavelength at a time), duration, and automatic or set pulse and range. iOLM: test limit, acquisition type and wavelengths (all in one shot).
    4. Pick when it starts (now, or in 5 minutes to 2 hours) and tick Both ends at once for a full cable from each end: the far end starts half the cable away, so the two ends never test the same fibre together.
    5. Press Start. FMS first confirms every fibre exists on that RTU and nothing is started yet; you then see one summary (fibres, Tasks, time, anything already running) and press OK to start.

    Time guide, measured on RGAC2: OTDR about the acquisition time plus 17 s per fibre per wavelength; iOLM Standard about 73 s per fibre. If an RTU is already busy, FMS shares it between Tasks, so both take longer.

    Overview: Live now (the first screen)

    Everything happening now on every RTU: the Reach route with each RTU's light, a card for every E2E run, Uni-dir tone and bulk Task (whoever started it, with live progress, and the fibre a tester is toning on their phone), who is online and what finished today. Click a card or an RTU to open it in the console. Light or Dark is at the top.

    Cable View

    Cable View (the cable health check): every fibre of one cable with its latest result, from both ends. Colour by Continuity (green straight, blue flipped, amber crossed, red Dis.), Loss 1550 or Last tested. A ribbon counts as flipped only when two mirror pairs agree, for example F1 to F12 and F2 to F11; one swapped pair shows as crossed. The bars under the totals show how much is tested, and To check lists the crossed, Dis., not found and high loss fibres; click one to open it. Report (Excel) saves the whole cable: continuity, iOLM loss from each end per wavelength with the both ways average, lengths and OTDR loss. Click a fibre for Live OTDR, Test now (one OTDR from either end, 5 to 60 s, or one Standard iOLM with the setup and wavelengths you pick; no FMS Task), its stored OTDR and iOLM traces from both ends (click one to see the trace, an iOLM shows its 1550 OTDR trace and events; pick another to lay over it), E2E and Uni-dir results, iOLM loss from each end with the both ways average, OTDR, and its history. Type F123, R11 F3 or RGAC 123 in the find box. While someone is testing the cable, the fibres under test pulse and the results fill in as they arrive.

    Real Time (live OTDR)

    In Cable View, click a fibre, press Test this fibre, then Live from one end (or Tools ▾, Real Time). The RTU repeats a short OTDR (3 s unless you pick another Shot length, 1 to 10 s) at 1550 nm with FMS automatic settings, with no FMS Task, starting each one as soon as FMS has stored the last, and draws each new trace (blue) over the first one (grey). New loss of 0.15 dB or more is marked in red with its distance from the RTU, so whoever is working on the fibre can see a bend or a bad joint appear. Click a red mark to zoom in; Use latest as reference starts the comparison again. One live OTDR per RTU; the RTU shows as testing while it runs, and it stops by itself after 10 minutes. Light on the fibre (a tone or traffic) stops the OTDR.

    Tasks: Run history

    Click an E2E run to see its report: every fibre coloured by what it found, the counts and a To check list. Single Tests are listed too.

    Finished work: every E2E run, Uni-dir session and FMS bulk Task, including cancelled ones. (The Tasks tab is different: it shows bulk Tasks running on one RTU now, and lets you cancel them.) It opens on Today, which is quickest; choose 7, 30 or 90 days for more. "App runs only" skips the FMS Tasks and loads fastest. The last list shows at once while it refreshes. Filter by result, type, RTU and person, click a row for detail, or export a CSV.

    For a finished FMS Task, the detail has Download files: the .sor file of every fibre in the Task, in one zip named after the cable, RTU, test type and start time. FMS makes the files 20 at a time, so a full ribbon set takes a minute or two.

    Who is online

    The pill at the top shows who is signed in (mobile or desktop) and what is running. Click it for the list.
